# Changelog

## 0.1.0 — 2026-10-15

- Two-parameter Weibull maximum-likelihood estimator with right censoring.
- Weka Explorer and CLI class `weka.classifiers.functions.WeibullSurvival`.
- Survival, hazard, cumulative hazard, quantiles, mean and median.
- Observed-information standard errors and 95% confidence intervals.
- Log-likelihood, AIC and BIC.
- Reproducible validation on two open software-smell survival datasets.
- Weka 3.8.7 and 3.9.6 CI matrix on Java 17.
